## Selected projects

### 01 / Superstore Sales & Profit Performance

**Business analytics · Tableau · Excel dataset**

An interactive dashboard exploring sales, profitability, and seasonal patterns in a fictional US retail business.

[![Superstore sales and profit dashboard](https://raw.githubusercontent.com/Tunguyen25/Tableau-Superstore-Sales-Performance/main/Superstone_Dashboard_Screenshot.png)](https://github.com/Tunguyen25/Tableau-Superstore-Sales-Performance)

| Business question | Analysis focus |
| :--- | :--- |
| Does higher revenue always mean higher profit? | Compare sales and profit margins across product sub-categories. |
| Which customer segments perform best? | Explore segment profitability by region. |
| When do sales peak? | Examine sales trends and year-end seasonality. |

**Finding highlighted in the project:** the Tables sub-category generates substantial revenue while recording a negative profit margin — showing why sales and profit should be evaluated together.

**Methods:** data relationships, aggregated profit-margin calculations, and interactive dashboard actions.

[View repository →](https://github.com/Tunguyen25/Tableau-Superstore-Sales-Performance) · [Explore live dashboard ↗](https://public.tableau.com/views/Superstone_Analysis/BusinessPerformanceDB?:language=en-US&:display_count=n&:origin=viz_share_link)

### 02 / Vietnam Administrative Units Dashboard

**Geographic analysis · Tableau Public · JSON data**

An interactive map for exploring Vietnam's administrative units and comparing ward-level counts across provinces and regions.

- **Explore geography:** select a province or region to filter the dashboard.
- **Compare distributions:** examine ward counts across localities.
- **Navigate hierarchies:** organize the view from region to province to ward.

**Methods:** geographic visualization, regional grouping, hierarchical data, and interactive filters. Source data is credited in the project to `thanglequoc/vietnamese-provinces-database`.

[View repository →](https://github.com/Tunguyen25/MapOfVietnamm) · [Explore live dashboard ↗](https://public.tableau.com/shared/M3PBZZ7S2?:display_count=n&:origin=viz_share_link)
